LEARNING THROUGH PRACTICE

My Reflection.

Looking back at the projects I have built, I can see how each one strengthened my skills, challenged me to solve problems, and helped me grow as a developer.

01 ModernTech Solutions Frontend · Employee Data Management and Login

ModernTech was one of my first team website projects: an HR system designed to help a company manage employee information and related processes. My assigned role focused on employee data management and login.

I worked on the frontend pages and features for:

  • A login interface for users to access the system.
  • An employee data page for displaying records and supporting employee management.
  • Navigation and interface details to help users move through the system.

I used HTML, CSS, JavaScript, and Bootstrap. One challenge was making the employee features work while keeping the pages consistent. Testing the functionality, checking my code, and coordinating with teammates helped me bring the different sections together. This project strengthened my frontend skills and showed me how each page contributes to a complete application.

02 ModernTech Solutions Backend · Employee Data Management and Login

In the backend phase, I continued working on employee data management and login, learning how the application could process requests, manage information, and communicate with a database.

  • Explored login requests and user authentication.
  • Learned how API routes, controllers, and models organise application logic and employee data operations.
  • Worked with MySQL and used Thunder Client to test API endpoints.

I used Node.js and Express and learned about API requests and middleware. When a request failed, I had to work out whether the issue was in a route, controller, database query, or request. I made progress by breaking the problem into smaller steps, reading error messages, and testing endpoints individually. This helped me understand how the backend components connect to the frontend.

03 StockWell E-commerce · Frontend, backend, and database development

StockWell was designed to help stokvels shop more conveniently by comparing supplier prices and organising bulk purchases. I contributed to both frontend and backend development, as well as database creation.

I worked on:

  • The home page, making the landing experience welcoming and visually engaging.
  • The product catalogue, displaying product images and supplier price comparisons.
  • The admin and member dashboards, contributing to their frontend and backend functionality.
  • Database tables and relationships for users, products, suppliers, stokvels, and stokvel members.

One challenge was finding suitable product images and displaying them clearly in the catalogue. I also worked to make the home page more appealing. I addressed these issues by correcting image paths and display styles, improving the layout, and refining the design to make the platform easier to navigate.

StockWell strengthened my frontend, backend, and database skills. It showed me how clear product images and an inviting home page can improve an e-commerce experience, and helped me understand how the parts of a full-stack application work together to address a real-world need.

04 My First Portfolio Personal project · HTML, CSS, and JavaScript

My first portfolio gave me space to present my development journey and experiment with a design that felt personal. I explored a dark theme, smoke effects, floating circles, and animated navigation. I worked on the home, About Me, Work, Interests, and Contact pages, along with responsive layouts and navigation between them.

Turning visual ideas into a working website was a challenge. I learned to troubleshoot navigation, filenames, CSS, background paths, and GitHub Pages deployment by checking file paths, organising project files, reviewing deployment settings, and testing changes rather than assuming they worked.

This portfolio has continued to evolve. The experience taught me that a site should not only look attractive; it also needs to be organised, functional, accessible, and tested after deployment.

05 What I have learned and where I am going Key lessons · Future goals

These projects have taken me from frontend interfaces to backend APIs and databases, through a community-focused e-commerce idea, and into independent portfolio design. Across them, I have learned the value of teamwork, planning, communication, patience, and continuous learning.

When something goes wrong, I am learning to break the problem into smaller steps, inspect the code and errors, test possible solutions, and learn from the result. I am proud of the progress I have made, while recognising that there is still more to learn. Going forward, I want to build confidence coding independently, strengthen my frontend and backend skills, and keep creating projects that show what I can do.
